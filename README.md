## Cara Seting Proxy Webshare di Berbagai Tools

Setelah paket aktif, kamu akan dapat tabel proxy berisi: IP, port, username, password. Tinggal masukkan ke tool yang dipakai.

**Browser (Chrome/Firefox)**
Pakai extension seperti FoxyProxy atau Proxy SwitchyOmega. Tambahkan profil baru, masukkan kredensial, simpan. Klik aktifkan sat butuh.

**Python (Requests/Scrapy)**
Tambahkan parameter `proxies` di request, dengan format `http://username:password@ip:port`. Untuk Scrapy, set di middleware atau settings.

**cURL**
Gunakan flag `-x` dikuti format `http://username:password@ip:port`. Sederhana, satu baris.

**Software Scraping (Octoparse, ParseHub)**
Masuk ke menu Proxy Settings, pilih Manual, paste daftar proxy yang diunduh dari dashboard Webshare dalam format yang sesuai.

**Multi-Login Browser (GoLogin, Multilogin, AdsPower)**
Sat membuat profil baru, di field proxy paste credentials Webshare. Tiap profil bisa pakai IP berbeda untuk akun yang dipisahkan.

Webshare menyediakan opsi unduh daftar proxy dalam berbagai format: TXT, CSV, JSON, dan langsung sebagai URL list. Jadi nggak perlu reformating manual setiap kali ganti tool.
